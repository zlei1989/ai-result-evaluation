## 4. 机制对照实验（回答「为什么不用 `justify="space-between"`」）

`space-between` 是**逐行**生效的：某一行只剩一个子元素时，它会被推到**左**端
（`base/toolbar.tsx` 的注释记着同一族事故）。两处「右边」因此都用 `marginInlineStart: 'auto'`。
在夹具页同一张卡上只改 DOM 内联样式，实测：

| 实验 | 改动 | 派发方式距右 / 距左 | 动作组距右 / 同行 |
|---|---|---|---|
| 1 | 本实现（auto 外边距）+ 隐藏「用量」那一格 | **0** / 546 | 0 / 同行 |
| 2 | 对照组：`justify-content: space-between` 且去掉 auto 外边距，同样隐藏用量 | 546 / **0**（跳到左边） | 0 / 同行 |
| 3 | 名称换成不可断长 token（动作组被挤到第二行） | 0 / 546 | **0** / **不同行** |

实验 2 就是被否掉的那个写法在真机上的形状；实验 3 是本实现与它拉开差距的那一格。
实验后已还原，基线复测与还原前逐项一致。
