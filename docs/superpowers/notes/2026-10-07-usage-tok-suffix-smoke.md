# 用量文案「tok 后缀 + 统一千分位」真机冒烟记录 — 2026-10-07

> 来源：用户在本会话直接给的口径（无对应计划/设计文档），原文「搜索 输入、缓存、输出 关键词，在所有对应的地方，
> 数字后面增加 tok 后缀，如 0,000 tok」。两处追问后的裁定：① = **统一千分位 + tok**（里程碑与台账行的裸数字一并
